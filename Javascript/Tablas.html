operadores de igualdad
Operador Descripción Ejemplos que devuelven el valor true
Igualdad (==) Si ambos operandos son iguales devuelve true en caso contrario false. No se comprueba el tipo de datos. 7 == y
"4" == '4'
x == "5"
false == false
Desigualdad (!=) Si ambos operandos no son iguales devuelve true en caso contrario false. No se comprueba el tipo de datos. x != y
x != 7
x != '5'
Igualdad estricta (===) Si ambos operandos son iguales y son del mismo tipo de datos devuelve true en caso contrario false. x === 5
y === 7
Desigualdad estricta (!==) Si ambos operandos no son iguales y/o no tienen el mismo tipo de dato devuelve true. x !== "5"
y !== '7'
4 !== '4'
Mayor que (>) Si el operando de la izquierda es mayor que el operando de la derecha devuelve true en caso contrario false. No se comprueba el tipo de datos. y > x
4 > 3
"4" > 3
Menor que (<) Si el operando de la izquierda es menor que el operando de la derecha devuelve true en caso contrario false. No se comprueba el tipo de datos. x < y
3 < 4
3 < "4"
Mayor o igual que (>=) Si el operando de la izquierda es mayor o igual que el operando de la derecha devuelve true en caso contrario false. No se comprueba el tipo de datos. y >= x
y >= 7
4 > 3
"4" > 3
"4" >= 4
Menor o igual que (<=) Si el operando de la izquierda es menor o igual que el operando de la derecha devuelve true en caso contrario false. No se comprueba el tipo de datos. x <= y
7 <= y
3 <= 4
3 <= "4"
"4" <= 4
operadores aritméticos
Operador Descripción Ejemplo
+ (suma) Operador binario. Devuelve la suma de dos operandos. 3 + 4 devuelve 7
x + 3 devuelve 8
- (resta) Operador binario. Devuelve la resta de dos operandos. 3 - 4 devuelve -1
x - 3 devuelve 2
* (multiplicación) Operador binario. Devuelve la multiplicación de dos operandos. 3 * 4 devuelve 12
x * 3 devuelve 15
/ (división) Operador binario. Devuelve el cociente de la división. Tenga en cuenta que la división entre 0 devuelve Infinity. 3 / 4 devuelve 0.75
x / 3 devuelve 1,667
3 / 0 devuelve Infinity
% (modulo) Operador binario. Devuelve el resto de la división. 3 % 4 devuelve 3
x % 3 devuelve 2
++ (incremento) Operador unario. Suma una unidad al operando. Este operador puede ir delante o detrás de la variable. El comportamiento es muy diferente puesto que si el operando es (++x) el valor devuelto será posterior de realizar la incrementación. En cambio si el operador es detrás (x++) primero se devuelve el valor y posteriormente se realiza la operación. ++x devuelve 6 puesto que primero se realiza la operación.
x++ devuelve 5 y el valor de x pasa a ser 6.
-- (decremento) Operador unario. Resta una unidad al operando. Su comportamiento es idéntico al descrito para el operador incremento (++). --x devuelve 4 puesto que primero se realiza la operación.
x-- devuelve 5 y el valor de x pasa a ser 4.
- (negación) Operador unario. Niega el valor del número. Es decir, los números positivos serán negativos y los negativos serán positivos. -x devuelve -5
- (-x) devuelve 5
operadores a nivel de bit
Operador Descripción Uso
AND (Y) Devuelve 1 si los 2 bits tienen el valor 1. En caso contrario es 0. x & y
OR (O) Devuelve 1 si alguno de los 2 bits tienen el valor 1. En caso contrario es 0. x | y
XOR (O exclusivo) Devuelve 1 si alguno de los 2 bits tienen el valor 1 pero si los 2 bits son 1 devolverá 0. En el último caso también será o. x ^ y
NOT (No) Invierte el valor del bit. Si el bit tenía el valor 1 pasará a 0 y viceversa. !x
Left shift (Desplazamiento izquierda) Desplaza los valores de los bits hacia la izquierda del número (x) el número de posiciones que se indican en (y). Los valores son rellenados con cero a la izquierda y los números iniciales (más a la izquierda) son desechados. Esta operación es equivalente a multiplicar por potencias de 2. x << y
Sign-propagation right shift (Desplazamiento a la derecha) Desplaza los valores de los bits hacia la derecha del número (x) el número de posiciones que se indican en (y). Los valores son rellenados con cero a la derecha y los números finales (más a la derecha) son desechados. Esta operación es equivalente a dividir en potencias de 2. Es importante resaltar que el signo del número es mantenido en el desplazamiento, dando lugar a números diferentes. x >> y
Zero-fill right shift (Rellenar con ceros a la derecha) Es igual que el desplazamiento a la derecha pero no se mantiene el signo en el desplazamiento. x >>> y
